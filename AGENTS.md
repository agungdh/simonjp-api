# AGENTS.md — simonjp-api

Simple Go REST API: `chi/v5` + `SQLite (modernc.org/sqlite, no CGO)` + `bun ORM` + `goose migrations` + `swaggo docs`.

## Layout

- `cmd/api/main.go` — entrypoint: load config → open bun DB → `goose.Up(bunDB.DB, "migrations")` → serve chi router. Swagger annotations (`@title`, `@host`, …) live here.
- `internal/config/config.go` — `PORT` (default `8080`), `DB_PATH` (default `data/app.db`), loads `.env` via godotenv.
- `internal/db/db.go` — opens SQLite with `_pragma=foreign_keys(1)&journal_mode(WAL)`, creates parent dir, returns `*bun.DB`.
- `internal/models/item.go` — bun models + shared DTOs (`ItemInput`, `ErrorResponse`) with swagger `example` tags.
- `internal/handlers/` — HTTP handlers, stdlib `encoding/json` only. Response helpers: `writeJSON` / `writeError`. Handler methods carry swaggo `@Router` annotations — keep them in sync with routes.
- `internal/routes/routes.go` — chi router: `GET /health`, `GET /swagger/*`, CRUD under `/api/items`.
- `migrations/` — goose SQL (`-- +goose Up/Down`). Auto-applied on boot.
- `docs/` — generated by swag (`docs.go`, `swagger.json/yaml`). Commit it. Regenerate after annotation changes.
- `data/` + `*.db` + `.env` are gitignored.

## Commands

```sh
cp .env.example .env
go mod tidy
go run ./cmd/api          # or: make run
make swag                 # regenerate docs/ after editing annotations
make migrate-up           # manual goose up (data/app.db)
make migrate-down
go vet ./...
go build -o bin/api ./cmd/api
```

Swagger UI: `http://localhost:8080/swagger/index.html`, spec: `/swagger/doc.json`.

## Conventions for changes

- New entity ≈ clone `items` flow: bun model in `internal/models/` → handler in `internal/handlers/` with swaggo annotations → mount in `internal/routes/routes.go` → new `migrations/NNNNN_*.sql` → `make swag`.
- Request/response DTOs must be exported structs in `internal/models` so swag can generate schemas (unexported `type foo struct` won't appear in docs).
- Error shape is `{"error": "..."}` (`models.ErrorResponse`).
- SQLite driver name is `"sqlite"` (modernc). Dialect for goose is `"sqlite3"`. Don't mix with `mattn/go-sqlite3`.
- Tests: no test suite yet. Verify manually: boot server, `curl` health + CRUD, check non-200 paths (400 invalid id/body, 404 missing row).
